# 🌐 Navegadores Web (Browsers)

> Configurações de navegadores de internet executados diretamente no Host.

---

## 🎯 Finalidade

Navegadores web são aplicações de interface gráfica que rodam nativamente no Host para tirar proveito total da aceleração de hardware (GPU) e renderização Wayland.

Esta pasta organiza ajustes de performance, privacidade e compatibilidade de APIs web essenciais para o fluxo de trabalho de desenvolvimento.
